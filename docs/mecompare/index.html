mecompare

Marginal effects and cross-model comparisons of effects in Stata

mecompare calculates marginal effects and compares them across models. It implements the framework of Mize, Doan, and Long (2019): the models are combined using seemingly-unrelated estimation with suest2 so that the difference in marginal effects across models accounts for cross-model covariances of effects, even though the models were estimated separately.

The comparisons mecompare handles include effects across nested models (e.g., mediation and confounding), across alternative predictors, across different outcomes, across different model types (for example ordinal versus nominal), and across models fit to separate groups or samples.

mecompare also automates comparisons of effects within a single model. This can be used to compare effect sizes across predictors, for tests of interaction, and for other within-model comparisons.

Installation

net install mecompare, from("https://tdmize.github.io/data") replace

mecompare requires suest2, which installs the same way (net install suest2, from("https://tdmize.github.io/data") replace), and it ships with metest, which automates non-standard tests of contrasts between rows of the mecompare table.

Where to start

  • Getting started walks through one comparison and explains the table.
  • Options goes through every option with an example of each; Plotting and tabulating results covers store() with coefplot and esttab.
  • The Examples in the sidebar reproduce the examples from Mize, Doan, and Long (2019) plus a within-model comparison; the Interactions pages reproduce the analyses of Mize (2019) on nonlinear interaction effects.
  • Examples from the help file runs the help file’s examples in full, and the help file itself is on the site, rendered from the installed version (help mecompare in Stata).

Citation

mecompare implements the methods proposed by Mize, Doan, and Long (2019). If you use mecompare, please cite:

Mize, Trenton D., Long Doan, and J. Scott Long. 2019. “A General Framework for Comparing Predictions and Marginal Effects Across Models.” Sociological Methodology 49(1): 152–189. https://doi.org/10.1177/0081175019852763

Related commands

Command What it does
suest2 Combines separately estimated models so that quantities from different models can be tested against each other. The engine underneath cross-model comparisons for mecompare.
metest Tests contrasts between rows of the tables produced by mecompare, meinequality, and totalme (or any posted margins results).
meinequality Summarizes how unequal the marginal effects of a categorical predictor are across its categories.
totalme Summarizes a predictor’s effect across all outcome categories of a multiple-outcome model in a single Total Marginal Effect.
